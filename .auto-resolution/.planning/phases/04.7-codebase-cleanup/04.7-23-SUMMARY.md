## Lessons Learned

1. **Pre-commit Hooks**: Complex hook chains (test → coverage → warnings → changelog) can make commits difficult. SKIP variable is essential for internal refactoring.

2. **Git Detection**: SPM auto-discovers files, so no Package.swift changes needed. Git detects renames at 95%+ similarity threshold.

3. **Concurrent Edits**: Pre-commit hooks stash/restore working directory, requiring careful management of staged vs unstaged changes.

4. **Sendable Constraints**: Swift 6 strict concurrency requires explicit Sendable constraints on generic parameters holding Sendable-conforming property storage.
