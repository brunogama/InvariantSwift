## Decisions Made

**1. SwiftTesting types in InvariantSwiftTesting target**

- FailurePersistence types (PersistedFailure, FailureDatabase, FailurePersistenceManager) are in SwiftTesting/ directory
- SwiftTesting/ is part of InvariantSwiftTesting target (not InvariantSwiftExperimental)
- Tests must import `@testable import InvariantSwiftTesting`

**2. Typealias pattern for Foundation conflicts**

- Foundation.Operation (NSOperation) is non-generic and shadows InvariantSwiftExperimental.Operation<Input, Output>
- Solution: `typealias Operation = InvariantSwiftExperimental.Operation` at file scope
- Pattern applies to other Foundation types (Date, URL, UUID conflicts are rare but possible)

**3. Test trait-based disabling**

- PropertyConfig static lenses not implemented → `.disabled("PropertyConfig static lenses not yet implemented")`
- ConfigBuilder not implemented → `.disabled("ConfigBuilder not yet implemented")`
- ConfigTemplate not implemented → `.disabled("ConfigTemplate not yet implemented")`
- Allows test file to compile while documenting missing features

**4. Size lens naming from Plan 14**

- Size.value would conflict with instance property (Swift compiler limitation)
- Implementation uses Size.valueLens instead
- Tests updated: `Size.value` → `Size.valueLens`
