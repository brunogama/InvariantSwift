  <action>
Fix Swift 6 Sendable conformance warnings:

1. For types that capture mutable state but are logically thread-safe:
   ```swift
   // Add @unchecked Sendable with justification
   /// Thread-safe: uses internal locking
   extension SomeType: @unchecked Sendable {}
   ```

2. For types with closures that need Sendable:
   ```swift
   // Add @Sendable to closure parameters
   public func map<U>(_ transform: @escaping @Sendable (T) -> U) -> Gen<U>
   ```

3. For actor isolation issues:
   - Add `nonisolated` where appropriate
   - Move state to actor-isolated properties

4. For metatype capture warnings:
   - Use explicit type parameters instead of capturing metatypes
   - Add Sendable constraints to generic parameters

5. Fix any "cannot be used to satisfy noncopyable" warnings

Pattern for common fixes:
```swift
// BEFORE: Warning about Sendable closure
func process(_ handler: @escaping (T) -> Void)

// AFTER: Explicit Sendable requirement
func process(_ handler: @escaping @Sendable (T) -> Void)
```
  </action>
