- Returns empty array (marker macro pattern)
- Documentation explains integration with @PropertyTest
- Follows exact pattern from ReproduceMacro

### RegressionExtractor.swift

- Defines `RegressionConfig` struct with:
  - `replayFirst: Bool` (default: true)
  - `maxExamples: Int?` (default: nil)
- Provides `extractConfig(from:)` for parsing @Regression attributes
- Provides `hasRegressionAttribute(_:)` for quick presence check
- Uses `Self` for static type references (SwiftLint compliant)

### RegressionMacroDeclaration.swift

- `@attached(peer)` macro declaration
- Default `replayFirst: true` for regression prevention
- Optional `maxExamples` parameter to limit replay count
- Comprehensive documentation including:
  - Basic usage examples
  - How it works (4-step process)
  - Environment variables
  - Comparison table: @Reproduce vs @Regression
  - Clear distinction: debugging vs regression prevention
