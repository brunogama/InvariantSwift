Implementation requirements:

1. **Extension on Property<T>** with three methods:
   - `cover(_ percentage: Double, when predicate: @escaping @Sendable (T) -> Bool, label: String) -> ClassifyingProperty<T>`
   - `classify(when predicate: @escaping @Sendable (T) -> Bool, label: String) -> ClassifyingProperty<T>`
   - `label(_ text: String) -> ClassifyingProperty<T>`

2. **Each method converts Property<T> to ClassifyingProperty<T>** by:
   - Preserving the original generator and assumption
   - Wrapping the predicate to call classification on context
   - Storing the classification requirements for later execution

3. **For .cover()**: Store coverage requirement (percentage threshold, condition, label) that ClassifyingPropertyRunner will check after all iterations complete.

4. **For .classify()**: Store conditional label that gets applied when predicate is true.

5. **For .label()**: Store unconditional label that always applies.

6. **Implementation pattern** (from research):
```swift
extension Property {
  public func cover(
    _ percentage: Double,
    when predicate: @escaping @Sendable (T) -> Bool,
    label: String
  ) -> ClassifyingProperty<T> {
    ClassifyingProperty(
      generator: self.generator,
      assumption: self.assumption
    ) { value, ctx in
      ctx.cover(label, percentage: percentage) { predicate(value) }
      return self.predicate(value)
    }
  }
}
```

7. **All public functions must have documentation comments** (/// style) with:
   - Description of what the method does
   - Parameter descriptions
   - Returns description
   - Example usage

8. **Use @Sendable closures** for Swift 6 concurrency compliance.

9. **No force unwraps, no fatalError** - make illegal states unrepresentable.

```swift
Property(generator: Gen.int) { n in n >= 0 }
  .cover(50, when: { $0 > 0 }, label: "positive")
  .classify(when: { $0 == 0 }, label: "zero")
  .label("non-negative check")
```

Implementation requirements:

1. **Add extension to ClassifyingProperty<T>** with same three methods:
   - `cover(_ percentage: Double, when predicate: @escaping @Sendable (T) -> Bool, label: String) -> ClassifyingProperty<T>`
   - `classify(when predicate: @escaping @Sendable (T) -> Bool, label: String) -> ClassifyingProperty<T>`
   - `label(_ text: String) -> ClassifyingProperty<T>`

2. **Chaining must accumulate** - each call adds to existing classifications, doesn't replace them.

3. **Implementation pattern for chaining**:
```swift
extension ClassifyingProperty {
  public func cover(
    _ percentage: Double,
    when predicate: @escaping @Sendable (T) -> Bool,
    label: String
  ) -> ClassifyingProperty<T> {
    ClassifyingProperty(
      generator: self.generator,
      assumption: self.assumption
    ) { value, ctx in
      // First run existing classifications
      let baseResult = self.predicate(value, ctx)
      // Then add new coverage check
      ctx.cover(label, percentage: percentage) { predicate(value) }
      return baseResult
    }
  }
}
```

4. **Order matters**: Classifications execute in the order they were chained.

5. **All public functions must have documentation comments**.

6. **Verify backward compatibility**: Existing tests in Tests/FunctionalTesting/ClassificationTests.swift should still pass.
