## @Roundtrip - Encode/Decode Testing

Automatically generates property tests that verify serialization roundtrips preserve values.

### Basic Usage

```swift
// JSON roundtrip (default)
@Roundtrip
struct User: Codable, Equatable {
  let id: UUID
  let name: String
  let age: Int
}

// Generates a test that verifies:
// encode(user) -> Data -> decode -> user' where user == user'
```

### Strategies

| Strategy | Use Case | Requirements |
|----------|----------|--------------|
| `.json` | REST APIs, persistence | `Codable`, `Equatable` |
| `.plist` | UserDefaults, plists | `Codable`, `Equatable` |
| `.hash` | Dictionary/Set keys | `Hashable` |
| `.custom` | Custom encoders | `Codable`, `Equatable` |

### JSON Roundtrip (Default)

```swift
@Roundtrip
struct APIResponse: Codable, Equatable {
  let data: [Item]
  let pagination: Pagination
}
// Tests: JSONEncoder -> Data -> JSONDecoder preserves value
```

### PropertyList Roundtrip

```swift
@Roundtrip(via: .plist)
struct AppSettings: Codable, Equatable {
  let theme: String
  let fontSize: Int
  let notifications: Bool
}
// Tests: PropertyListEncoder -> Data -> PropertyListDecoder preserves value
```

### Hash Stability

```swift
@Roundtrip(via: .hash)
struct CacheKey: Hashable {
  let path: String
  let query: [String: String]
}
// Tests: hashValue is consistent within same run
// Note: Hash values may differ between runs (Swift uses random seeding)
```

### Custom Encoder/Decoder

```swift
@Roundtrip(via: .custom(encoder: "ISO8601JSONEncoder", decoder: "ISO8601JSONDecoder"))
struct Event: Codable, Equatable {
  let id: UUID
  let timestamp: Date
}
// Uses your custom encoder/decoder types
```

### Configuration

```swift
@Roundtrip(
  via: .json,
  iterations: 500,    // More iterations for complex types
  seed: 12345,        // Fixed seed for reproducibility
  maxShrinks: 2000    // More shrinking for better counterexamples
)
struct ComplexModel: Codable, Equatable { ... }
```

### Requirements

- Type must conform to `Codable` (for `.json`, `.plist`, `.custom`)
- Type must conform to `Equatable` (for value comparison)
- Type must conform to `Hashable` (for `.hash` strategy)
- Type must have a `Gen<T>.arbitrary` generator (from `@Arbitrary` or manual)

### Common Patterns

**With @Arbitrary:**
```swift
@Arbitrary
@Roundtrip
struct User: Codable, Equatable {
  let name: String
  let email: String
}
// @Arbitrary generates the Gen<User>.arbitrary
// @Roundtrip uses it for property testing
```

**Detecting Lossy Encoding:**
```swift
// This will FAIL if Date loses precision during JSON roundtrip
@Roundtrip
struct Event: Codable, Equatable {
  let timestamp: Date  // Default JSONEncoder uses Double, may lose precision
}

// Fix: Use custom encoder with ISO8601 date strategy
```

### Diagnostics

- "Type must be struct or class" (not enum/protocol)
- "Type must conform to Equatable" (missing conformance for .json/.plist/.custom)
- "Type must conform to Hashable" (missing conformance for .hash)

See also: [COOKBOOK.md](COOKBOOK.md#roundtrip-testing-recipes) for practical recipes.

/// Choose the appropriate strategy based on your type's serialization requirements.
public enum RoundtripStrategy: Sendable {
  /// JSON roundtrip using `JSONEncoder` and `JSONDecoder`.
  ///
  /// Best for: REST APIs, persistence, cross-platform serialization.
  /// Requires: `Codable`, `Equatable`
  case json

  /// PropertyList roundtrip using `PropertyListEncoder` and `PropertyListDecoder`.
  ///
  /// Best for: UserDefaults, plist files, Apple-native persistence.
  /// Requires: `Codable`, `Equatable`
  case plist

  /// Hash stability verification.
  ///
  /// Verifies that `hashValue` is consistent within the same program execution.
  /// Best for: Dictionary keys, Set elements, cache keys.
  /// Requires: `Hashable`
  ///
  /// - Note: Hash values may differ between program runs due to Swift's random seeding.
  case hash

  /// Custom encoder/decoder roundtrip.
  ///
  /// Use when you need custom encoding strategies (date formats, key mapping, etc.)
  /// Requires: `Codable`, `Equatable`
  ///
  /// - Parameters:
  ///   - encoder: The encoder type name (e.g., "MyCustomEncoder")
  ///   - decoder: The decoder type name (e.g., "MyCustomDecoder")

}
