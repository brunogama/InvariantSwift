**IdempotentMacro.swift:**
Create `public struct IdempotentMacro: PeerMacro` following PropertyMacro.swift pattern:

1. **Expansion function:**
   - Validate declaration is FunctionDeclSyntax (emit diagnostic if not)
   - Extract parameters using ParameterExtractor.extract()
   - Validate at least one parameter exists
   - Check for async via `funcDecl.signature.effectSpecifiers?.asyncSpecifier`
   - Extract config from node arguments (iterations, applicationCount)

2. **Generate wrapper enum** (to avoid peer+peer macro conflict):
   - Name: `{funcName}_IdempotentTest`
   - Contains static `@Test` function named `run`
   - Mark enum as private

3. **Build test body:**
   - Generator declaration using GeneratorInference.infer() for each parameter
   - For multiple parameters, use flatMap chain pattern from PropertyMacro
   - Property definition with closure that:
     ```
     var current = f(input)
     for _ in 1..<applicationCount {
       current = f(current)
     }
     let next = f(current)
     return current == next
     ```
   - PropertyConfig with iterations from macro config
   - Result handling with switch (success/failure/gaveUp)

4. **Handle async functions:**
   - If async, use `await` in function calls within closure
   - Generate async throws signature for test function

**DeterministicMacro.swift:**
Create `public struct DeterministicMacro: PeerMacro` with same structure:

1. Same validation and extraction as IdempotentMacro

2. Build test body with property closure that:
   ```
   let results = (0..<callCount).map { _ in f(input) }
   return results.dropFirst().allSatisfy { $0 == results[0] }
   ```
   Or simpler for callCount=2:
   ```
   let call1 = f(input)
   let call2 = f(input)
   return call1 == call2
   ```

**MacroPlugin.swift:**
- Add `IdempotentMacro.self` to providingMacros array
- Add `DeterministicMacro.self` to providingMacros array

**CRITICAL:** Use pure SwiftSyntax AST builders only. NO string interpolation for code generation. Follow the buildXxx() helper pattern from PropertyMacro.swift.
