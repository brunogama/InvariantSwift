## Technical Details

### Import Pattern Discovery

**Problem**: Advanced/ directory excluded from InvariantSwift target
**Solution**: Tests must import `@testable import InvariantSwiftExperimental`

**Before** (incorrect):
```swift
import Testing
import Foundation
import InvariantSwiftCore
@testable import InvariantSwift
```

**After** (correct):
```swift
import Testing
import Foundation
@testable import InvariantSwift
@testable import InvariantSwiftExperimental  // Required for Advanced/ types
```

### Architectural Understanding

**Package.swift structure**:
- `InvariantSwift` target **excludes**: Advanced/, Coverage/, Fuzzing/, Reliability/
- `InvariantSwiftExperimental` target **includes**: Advanced/, Coverage/, Fuzzing/, Reliability/
- Tests requiring experimental features must import both targets

### API Gap Analysis

**Operation Type** (Linearizability):
```swift

  let call: Any
  let response: Any

```

**Lens Extensions** (LensSystem):
```swift

// Missing implementation:

  static let iterations: Lens<PropertyConfig, Int> = ...
```

**PropertyRunner Coverage Methods**:
