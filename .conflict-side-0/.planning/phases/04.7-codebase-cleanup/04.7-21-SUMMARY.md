## Knowledge Captured

### ConfigTemplate Usage Pattern
```swift
// Development: Fast feedback (25 iterations)
let devConfig = ConfigTemplate.development

// CI: Thorough testing (200 iterations)
let ciConfig = ConfigTemplate.ci

// Debug: Reproducible with seed (10 iterations)
let debugConfig = ConfigTemplate.debug(seed: 12345)
```

### PropertyConfig Immutability Constraint
```swift
// ❌ Doesn't work - PropertyConfig has `let` properties
ConfigBuilder<PropertyConfig>
  .from(.default)
  .set(\.iterations, to: 300)  // Error: No WritableKeyPath

// ✅ Works - Template approach
let config = ConfigTemplate.development  // Returns configured PropertyConfig
```

- Template pattern (static presets) simpler than builder for common configurations
