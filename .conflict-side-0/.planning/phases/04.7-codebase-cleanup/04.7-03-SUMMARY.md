## Technical Decisions

### Directory-Specific SwiftLint Configuration
**Decision:** Create `.swiftlint.yml` in `Tests/InvariantSwiftMacroTests/` to disable length rules

**Rationale:**
- Macro expansion tests inherently require long test functions for complete expected outputs
- assertMacroExpansion calls must include full macro expansions (can't be shortened)
- Test suites are cohesive and shouldn't be split across files
- Directory config eliminates need for per-file blanket disables

**Alternatives considered:**
1. Split tests into smaller files → Breaks cohesive test suites
2. Raise global limits → Weakens limits for all files
3. Per-file blanket disables → Requires disable comments in every file

**Chosen:** Directory config (most maintainable, scoped impact)

### Trailing Comma Conflict Resolution
**Decision:** Disable `trailing_comma` rule in directory config

**Rationale:**
- swift-format (Google style) adds trailing commas to multi-line collections
- SwiftLint's trailing_comma rule flags these as violations
- Pre-commit hook runs swift-format before SwiftLint, creating conflict

**Alternatives considered:**
1. Remove trailing commas manually → Undone by swift-format on next commit
2. Disable swift-format for macro tests → Loses other formatting benefits
3. Update swift-format config → Requires global style change

**Chosen:** Disable SwiftLint rule in directory (preserves formatter, scoped impact)
