**Components:**
1. **FlakeDetectionConfig** - Configuration for flake detection runs
   - `runs: Int = 100` - Number of test runs
   - `seeds: [UInt64]?` - Optional fixed seeds
   - `flakinessThreshold: Double = 0.01` - 1% failure rate threshold
   - `failOnFlaky: Bool = false` - Whether to fail on flakiness

2. **FlakeDetectionResult** - Comprehensive flakiness analysis
   - Tracks passes, failures, total runs
   - Records failing seeds for reproduction
   - Calculates flakiness score (0.0-1.0)
   - Provides actionable recommendations
   - Includes FlakeStatistics from FlakeHunter actor

3. **FlakeRecommendation** - Four-level guidance
   - `.stable` - No action needed (0 failures)
   - `.investigate` - Low flakiness (< 10%)
   - `.quarantine` - High flakiness (≥ 10%)
   - `.fix` - Consistently failing (100% failures)

4. **runPropertyWithFlakeDetection** - Core integration function
   - Runs property test N times with different seeds
   - Records each execution in FlakeHunter actor
   - Calculates flakiness score (minority outcome / total runs)
   - Returns comprehensive FlakeDetectionResult

5. **Safe Collection Access** - Helper extension
   - `Collection[safe: Index]` returns Optional instead of crashing
   - Used for seed array access

**Integration Points:**
- Leverages existing `FlakeHunter` actor for statistical analysis
- Uses `PropertyRunner.runProperty()` for test execution
- Records `TestExecution` with environment snapshots
- Retrieves `FlakeStatistics` for pattern analysis

## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Flakiness score = min(passes, failures) / total | Minority outcome indicates flakiness; 0.5 is maximally flaky |
| Four-level recommendations (stable/investigate/quarantine/fix) | Actionable guidance based on failure patterns |
| Safe collection subscript | Prevents crashes when seed array shorter than runs |
| failOnFlaky default false | Warnings first, developers opt-in to fail |
| Threshold default 1% | Balances sensitivity with noise tolerance |
| Reuse existing FlakeHunter | Leverage comprehensive statistical analysis infrastructure |

## Technical Notes

### Flakiness Score Calculation

```swift
let flakinessScore = Double(min(passes, failures)) / Double(runs)
```

- 100 passes, 0 failures → 0.0 (stable)
- 98 passes, 2 failures → 0.02 (low flakiness)
- 50 passes, 50 failures → 0.5 (maximally flaky)
- 0 passes, 100 failures → 0.0 (consistently failing)

### Integration with FlakeHunter

The function wraps PropertyRunner execution and feeds results to FlakeHunter:

```swift
for i in 0..<runs {
  let seed = seeds?[safe: i] ?? UInt64.random(...)
  let result = runner.runProperty(property, config: config)

  let execution = TestExecution(...)
  await hunter.recordExecution(execution)

  // Track passes/failures
}

// Get comprehensive statistics
let statistics = await hunter.getStatistics(for: testId)
```
