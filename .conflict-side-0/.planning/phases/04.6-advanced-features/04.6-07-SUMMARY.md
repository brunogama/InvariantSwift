## Knowledge Artifacts

### Key Learnings

1. **Module Boundaries Matter:** Extensions that depend on types in other targets must be placed in the dependent target (PropertyResult+Report → Presentation)

2. **Swift 6 Strictness:** Multi-line string literals in computed properties require explicit `return` statements

3. **Lint Compliance:** Large generated HTML/CSS requires extension-based modularization to meet type body length limits

4. **Seed API:** Seed uses `rawValue` property, not `value` (common mistake)

### Patterns Established

1. **HTML Generation Pattern:**
   ```swift
   private func section(_ data: ReportData) -> String {
     return """
       <div class="section">
         \(escapeHTML(data.field))
       </div>
       """
   }
   ```

2. **SVG Chart Pattern:**
   ```swift
   public func chart(data: [(String, Int)]) -> String {
     var svg = svgHeader()
     svg += drawBackground()
     svg += drawData(data)
     svg += svgFooter()
     return svg
   }
   ```

3. **Extension Splitting Pattern:**
   ```swift
   // Main type
   public struct Generator { ... }

   // CSS in extension
   extension Generator {
     fileprivate var embeddedCSS: String { ... }
   }

   // Sections in extension
   extension Generator {
     fileprivate func headerSection() -> String { ... }
   }
   ```

### Anti-Patterns Avoided

1. ❌ **External CSS files** - Would break offline viewing
2. ❌ **Large monolithic types** - Violates lint rules
3. ❌ **String concatenation for HTML** - String interpolation is cleaner
4. ❌ **Missing HTML/XML escaping** - Security vulnerability
5. ❌ **Hardcoded styling** - Use configurable ChartConfig

## Maintenance Notes

### Common Issues

**Issue:** HTML report doesn't display correctly
- **Cause:** Missing HTML escaping
- **Fix:** Use `escapeHTML()` for all user-provided text

**Issue:** SVG chart renders incorrectly
- **Cause:** XML special characters not escaped
- **Fix:** Use `escapeXML()` for all SVG text content

**Issue:** Type body length violation
- **Cause:** Large HTML/CSS strings in main type
- **Fix:** Extract into extensions or separate methods
