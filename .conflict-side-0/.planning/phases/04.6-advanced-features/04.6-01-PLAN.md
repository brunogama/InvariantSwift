  <action>
Create Property+Combinators.swift with logical operator overloads:

1. Define `&&` operator (AND - conjunction):
   - Takes two `Property<T>` with same generator
   - Returns `Property<T>` that short-circuits on first failure
   - Pattern: `guard lhs.predicate(value) else { return false }; return rhs.predicate(value)`

2. Define `||` operator (OR - disjunction):
   - Takes two `Property<T>` with same generator
   - Returns `Property<T>` that short-circuits on first success
   - Pattern: `if lhs.predicate(value) { return true }; return rhs.predicate(value)`

3. Add `implies` method to Property<T>:
   - Takes precondition closure `(T) -> Bool`
   - Returns property that discards when precondition false (not failure!)
   - Use existing PropertyEvaluation.discard pattern from Property.swift
   - Pattern: `!precondition(value) || self.predicate(value)` for Bool return
   - Also support PropertyEvaluation return: when precondition false, return .discard

4. Add operator precedence group `PropertyCombinatorPrecedence`:
   - Lower than comparison operators (so `a > 0 && property` works)
   - Higher than assignment
   - Left associative

5. Full documentation with examples showing:
   - Combining properties: `positiveProperty && evenProperty`
   - Conditional testing: `property.implies { $0 > 0 }`
   - Short-circuit evaluation behavior

All implementations must be `@Sendable` and work with Swift 6 strict concurrency.

  <name>Task 2: Implement forAll Block Syntax</name>
  <files>Sources/InvariantSwift/Core/ForAll.swift</files>
  <action>
Create ForAll.swift with global `forAll` functions for ergonomic property definition:

1. Single-parameter forAll with type inference (uses Arbitrary):
```swift
public func forAll<A: Arbitrary & Sendable>(
  _ check: @escaping @Sendable (A) -> Bool
) -> Property<A>
```

2. Two-parameter forAll with type inference:
```swift
public func forAll<A: Arbitrary & Sendable, B: Arbitrary & Sendable>(
  _ check: @escaping @Sendable (A, B) -> Bool
) -> Property<(A, B)>
```

3. Explicit generator variants (1-3 parameters):
```swift
public func forAll<A: Sendable>(
  _ gen: Gen<A>,
  check: @escaping @Sendable (A) -> Bool
) -> Property<A>

public func forAll<A: Sendable, B: Sendable>(
  _ genA: Gen<A>,
  _ genB: Gen<B>,
  check: @escaping @Sendable (A, B) -> Bool
) -> Property<(A, B)>
```

4. PropertyEvaluation return variants:
```swift
public func forAll<A: Arbitrary & Sendable>(
  _ check: @escaping @Sendable (A) -> PropertyEvaluation
) -> Property<A>
```

5. Use Gen.zip for multi-parameter variants to combine generators.

6. Documentation showing:
   - Type inference: `forAll { (n: Int) in n + 0 == n }`
   - Explicit generators: `forAll(Gen.int(in: 1...100)) { n in n > 0 }`
   - Multiple parameters: `forAll { (a: Int, b: Int) in a + b == b + a }`
