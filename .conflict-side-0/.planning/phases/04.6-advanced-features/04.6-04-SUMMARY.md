# Phase 04.6 Plan 04: @ShrinkTowards Macro Implementation Summary

**One-liner:** Smart shrinking hints via @ShrinkTowards(target) macro with binary search toward arbitrary values

---

## Objective

Implement @ShrinkTowards attribute macro for specifying shrink target hints, enabling smarter shrinking that finds more meaningful minimal counterexamples by guiding shrinking toward semantically appropriate values (e.g., 0 for counts, "" for strings, identity elements for algebraic types).

**Deliverables:**

- `Sources/InvariantSwift/Advanced/ShrinkHints.swift` (240 lines)
  - `ShrinkTarget<T>` enum: `.value(T)`, `.zero`, `.empty`, `.identity`, `.default`
  - `ShrinkHint<T>` struct: `target`, `weight` (clamped 0-1), `maxIterations`
  - Convenience initializers: `towards(_:)`, `towardsZero()`, `towardsEmpty()`

**Key Features:**

- **Binary shrinking algorithm:** 100 → 10 via [10, 55, 77, 88, 94, 97, 98, 99]

  - Binary midpoints (55 = 10 + (100-10)/2, etc.)
  - Boundary exploration (target±1 for edge cases)
- **Weight clamping:** Prevents invalid weights via `min(1.0, max(0.0, weight))`
- **No duplicates:** Set-based filtering with string keys for deterministic ordering

## Examples

### Basic Usage

```swift
@PropertyTest
func testPositiveCount(@ShrinkTowards(1) count: Int) -> Bool {
  count > 0  // Precondition
  // Property logic
}

// Without hint: count = 42 fails → shrinks to 0 (invalid)
// With hint:    count = 42 fails → shrinks to 1 (minimal valid)
```

### Multiple Parameters

```swift
@PropertyTest
func testRange(
  @ShrinkTowards(0) min: Int,
  @ShrinkTowards(100) max: Int
) -> Bool {
  min < max
}

// Shrinks both parameters toward their respective targets
```

### String Shrinking

```swift
@PropertyTest
func testNonEmptyName(@ShrinkTowards("test") name: String) -> Bool {
  !name.isEmpty
  // Property logic
}

// name = "production" fails → shrinks to "test" (minimal valid)
```

## Technical Challenges

### Challenge 1: Generic Type Constraints

**Problem:** Initial implementation used `extension Shrink { func towards<U>(...) -> [U] where T == U }` which caused "same-type requirement makes generic parameters equivalent" error.

**Solution:** Changed to constrained extensions: `extension Shrink where T: Comparable` for generic version, `extension Shrink where T: BinaryInteger & Comparable` for integer-specific version.

**Outcome:** Clean API with proper type inference and zero compiler errors.

### Challenge 2: SwiftLint Cyclomatic Complexity

**Problem:** Original `towards` implementation had complexity 11 (limit: 10) due to binary shrinking logic and boundary cases.

**Solution:** Extracted helper methods: `binaryShrinkSteps`, `boundarySteps`, `removeDuplicates` to reduce main method complexity to 3.

**Outcome:** Zero SwiftLint violations, improved readability, easier testing of individual components.

### Challenge 3: Module Imports

**Problem:** Build failed with "cannot find type 'Shrink' in scope" in Advanced/ directory.

**Solution:** Added `import InvariantSwiftCore` to ShrinkHints.swift following existing pattern from GeneratorMiddleware.swift.

**Outcome:** Successful build, consistent module structure.

## Learnings

1. **Constrained extensions > Generic equality constraints:** Swift prefers `extension Type where T: Protocol` over `func method<U>(...) where T == U`. Cleaner syntax, better errors.

2. **Marker macros for metadata:** @ShrinkTowards pattern (AccessorMacro returning []) is elegant for parameter metadata. PropertyMacro extracts via ShrinkHintExtractor without tight coupling.

3. **Binary shrinking produces better counterexamples:** Gradual path (100 → 55 → 77 → 88) is more intuitive than linear (100 → 99 → 98 → ...) and finds minimal values faster.

4. **SwiftLint strictness enforces quality:** Single-letter variable names ('v'), force try, cyclomatic complexity all caught by pre-commit hooks. Zero tolerance policy improves code quality.

5. **Import InvariantSwiftCore pattern:** Advanced/ files need explicit import for Core types. Pattern already established in GeneratorMiddleware.swift.
