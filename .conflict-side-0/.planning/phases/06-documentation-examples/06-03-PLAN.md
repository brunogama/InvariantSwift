/// A generator that produces random values of type `T`.
///
/// Generators are the source of randomness in property tests. They produce
/// values controlled by a seed (for reproducibility) and size (for complexity).
///
/// ## Built-in Generators
///
/// InvariantSwift provides generators for all Swift standard types:
///
/// ```swift
/// Gen<Int>.int                    // Any integer
/// Gen<Int>.int(in: 0...100)       // Integer in range
/// Gen<String>.string              // Any string
/// Gen<Bool>.bool                  // true or false
/// ```
///
/// ## Composing Generators
///
/// Combine generators to create complex test data:
///
/// ```swift
/// let pointGen = Gen.zip(Gen<Int>.int, Gen<Int>.int)
///     .map { Point(x: $0, y: $1) }
/// ```
///
/// ## Custom Types
///
/// Use `@Arbitrary` macro for automatic generation:
///
/// ```swift
/// @Arbitrary
/// struct User {
///     let name: String
///     let age: Int
/// }
/// // User.arbitrary is now available
/// ```
///
/// - Important: Generators are deterministic given the same seed.
///
/// ## Topics
///
/// ### Creating Generators
/// - ``int``
/// - ``int(in:)``
/// - ``string``
/// - ``array(_:count:)``
///
/// ### Transforming Generators
/// - ``map(_:)``
/// - ``flatMap(_:)``
/// - ``filter(_:)``
///
/// ### Combining Generators
/// - ``zip(_:_:)``
/// - ``oneOf(_:)``
public struct Gen<T> { ... }
```
