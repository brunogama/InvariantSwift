
# InvariantSwift — OpenSpec

This repository uses OpenSpec for change planning and agent execution.

## Where to start
- Read: `openspec/project.md`
- Then read the relevant capability spec under: `openspec/specs/**/spec.md`
- Implement work only through an approved change under: `openspec/changes/<change-id>/`

## Rules
- Specs in `openspec/specs/` are the source of truth.
- Change folders contain **proposed** deltas and task checklists.
- Do not implement a change until its proposal and spec deltas are aligned and reviewed.
